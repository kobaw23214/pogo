# 图片下载、打包和验证

真实照片要先保存为项目文件，再随项目快照运行。外链能在独立浏览器标签页
打开，不能证明它获准在 HTML Preview 或受管网站中作为图片加载。

## 在开发工作区准备资源

1. 从用户指定的搜索来源查找真实图源，区分搜索页、跳转链接和实际图片。
   保留来源与季节/主题的对应关系，不把一个主题的结果改标签冒充另一个主题。
2. 若当前 Bash 可用并获准联网，可用 `curl` 或 Python 标准库下载。不要在
   `web_service` 应用中写下载/代理逻辑；应用及其子进程不能主动建立外部连接。
   命令的网络权限仍由平台设置决定，读取本 Skill 不授予或改变网络权限。
3. 下载时设置连接/总超时、文件大小上限和有界重定向；验证 HTTP 成功、文件
   实际为图片且大小合理。防盗链错误页、登录页或验证码即使 HTTP 200 也不能
   保存成“成功的图片”。使用临时文件，确认成功后再替换目标，失败移除临时文件。
4. 用真实文件类型选择扩展名和 `Content-Type`，例如 JPEG → `.jpg` /
   `image/jpeg`，PNG → `.png` / `image/png`。可使用可用的 `file --mime-type`
   和图片解码器检查；只看 URL 后缀、响应的文件名或 HTML 中的 alt 不足以验证。
5. 存到当前 `project_root/assets/images/`，不要仅放在项目以外的 uploads 或
   下载目录。不要为了带入一张图而把整个用户工作区作为项目快照。
   浏览器下载需要等到 `state:saved` 且有 path；之后再把真实文件复制到项目内。

如果命令因沙箱或网络策略拒绝而未执行，记录这个确切边界，不关闭隔离、不换
未授权执行器绕过。没有实际下载回执时，不宣称“浏览器下载受限”。图源失效或
需要登录时更换用户允许的公开来源；不能完成则保留未完成项，不用插画伪装照片。

## 使用项目相对路径

```html
<img src="./assets/images/spring-1.png" alt="老君山春景" loading="lazy">
```

CSS 中的路径相对于 CSS 文件，例如 `assets/style.css` 使用
`url('./images/spring-1.png')`。不要用 `/assets/...` 根绝对路径，也不要保留
外域 `<img src="https://...">` 或远程 CSS 背景图。静态资源不应依赖服务运行时
下载，或依赖用户浏览器访问外站图床。

HTML Preview 会提供项目内资源。受管 Python/Node.js 应用还必须提供相应静态
HTTP 路由，不能只服务 `/`、`assets/app.js` 和 `assets/style.css`。例如在已有
Python 显式静态文件表中增加真实图片条目：

```python
STATIC_FILES["/assets/images/spring-1.png"] = (
    "assets/images/spring-1.png", "image/png"
)
```

沿用已有安全的二进制读取和响应逻辑，使用 `rb` 读取、写入原始 bytes，并设置
正确 MIME 和长度。文件列表只包含项目内实际资源，不把任意用户输入作为宿主
文件路径、不暴露应用源码或 `/data`。Node.js 同样用 `Buffer` 响应图片，不把
二进制当 UTF-8 文本解码。应用路由不包含网关前缀；gateway 会剥离前缀后转发。

## 验收真实图片

- 核对每张图片确实在项目内，格式、尺寸和主题对应正确，来源记录没有凭空编造。
- 受管服务修改后，明确 restart 同一 service，再确认新 generation ready；
  只改工作区文件不会更新运行快照。`/data` 的业务数据不因更新图片被清空。
- 检查图片请求返回 200 和正确 MIME，不是 SPA 的 HTML fallback 或 404 页面。
- 在浏览器滚动到 lazy 图片所在区域，检查 `complete`、`naturalWidth > 0`、
  `naturalHeight > 0`，并看截图确认内容是用户要的真实照片。DOM 有 img/alt、
  页面入口健康检查 200、插画能显示，都不能代替图片加载和内容验收。
- 图片仍失败时，区分路径/静态路由 404、错误 MIME、损坏文件和外域 CSP 拦截。
  用可用的浏览器诊断工具读真实回执，不反复修改脚本猜测；不要放宽脚本、外部
  API 或受管应用出网权限来掩盖缺失的本地资源。
