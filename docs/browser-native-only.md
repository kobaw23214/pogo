# 原生浏览器单一路径迁移

> 2026-10-12 历史定位：本文保留 2026-10-06 至 10-08 的迁移、Docker 与 Electron 阶段记录。下文的“唯一桌面 Chromium”、会话级共享租约及“最新部署”均指当时版本，不是 W2 当前默认。W2 源码采用 Docker 内同一真实 Chromium Page：每个会话拥有私有 profile，同会话 Sheet 共享网站登录态，每张 Sheet 绑定独立原生窗口与 Wayland output，接管按页生效；实时画面经 VP8 / Go-Pion WebRTC，截图只用于工具证据和元素引用。当前链路、退役范围和验收边界见 [Wayland browser-use 单一路径](browser-wayland.md)；是否正式发布以本次最终验收记录为准。

本机 2026-10-08 已进一步切换为唯一的桌面 Chromium 路径，旧托管 worker 停止且无自动回退；browser-use 工具契约继续复用。当前部署事实见 [Pogo Desktop 本机部署记录](desktop-browser-release.md)。

源码收敛日期：2026-10-06。本文说明当前实现及发布要求；源码和本地验证不代表运行中的 Docker 服务已更新。

## 唯一执行链路

`Agent → browser → BrowserGate 任务授权 → Go 会话桥 → 私有 worker → Chromium BrowserContext`

页面动作、截图、只读元素引用、CDP、Network/Console/Debugger 和人工接管共享该上下文。子 Agent 通过父会话的 FD 通道使用同一执行器，继续遵循任务授权、串行操作、会话隔离、取消和人工租约。前端没有打开或 SSE 没有订阅者时，已授权任务仍能执行。

未配置 worker 时，页面状态返回 `backend: unavailable`，操作明确失败；连接错误同样报告不可用，不选用旧后端。普通对话和文件功能仍可使用。没有 legacy 开关、iframe 执行器、SSE browser_request 派发或浏览器结果回填；旧 browser_result 请求返回退役错误，不能完成原生在途操作。

## 退役范围

- 删除 BrowserPane 的同源 iframe 自动化、DOM 注入、页面自定义 pick-data 钩子、执行器注册表、SSE 命令和结果回传。
- 删除 `api_read`、`auth_status` 及 Cookie/token 复制、存储键猜测和独立 Node HTTP 读取实现。登录由 Chromium 与网站自身维护。
- 删除 `eval` 动作别名。JavaScript 统一使用 `devtools` 的 `Runtime.evaluate`；执行脚本或新增请求具有外部效果，不能当成只读证据。
- 退役动作在整批执行前拒绝，没有旧动作到新请求的隐式转换。旧凭据管理 HTTP 路由仅返回 410，不创建 worker、不接触网站。
- 浏览器仍只有一条原生执行链；Dock 的每张浏览器 Sheet 对应同一会话 BrowserContext 内的独立 Page。单一执行器不限制页签数量。

`snapshot/find/click/type/extract/batch` 等页面操作和 `calculate` 观察量值辅助不是第二条浏览器路径。文件预览、PDF iframe、引用面板和独立业务嵌入也不属于 Agent 浏览器执行器，不因本次退役删除。旧面板注册数据只用于保存条目迁移，不能作为 Agent 执行回退。

## 保存条目迁移

前端对各 Dock 存储范围执行版本化、可重试的本地迁移。修改前保存原始书签、页签与已有新书签备份；成功后写入完成标记。已经迁移的范围不重复导入；异步解析期间其他窗口改动了原始数据时停止，保留新数据并提示重新加载。

优先使用旧书签保存的 `source` 原始网址。仅有本应用 `/panels/...` 的条目调用 `POST /api/browser/migrate-urls`，输入 `urls` 数组（最多 256），返回 `mappings` 数组，每项含原 `url` 和 `resolved_url` 或 `error`。服务只查询旧注册表，不创建代理、不导航、不调用 worker；查询与 fragment 予以保留，兼容旧代理的路径语义。

无法解析的条目保留为可编辑的待修复书签。旧浏览器/面板页签的地址存入书签；旧版迁移产生的单个浏览器入口由当前会话的真实页面绑定取代，不能再把已经绑定不同页面的新 Sheet 合并。迁移本身不打开网站、不重放历史工具调用。新书签直接保存原始网址，提供创建、修改、删除、导入和导出。只有明确提交合法原始地址后才访问网站。

## 浏览器 Sheet 与执行目标

每张 Sheet 保存独立 ID，并绑定会话、`context_ref` 与 `tab_id`。`context_ref` 在一个 BrowserContext 存续期间稳定，接管或取消产生的 generation 变化不改变它；重建上下文则更换标识。仅保存 `t1` 无法区分重启前后的页面，因此失效绑定不能自动指向新上下文的同名页签。

“＋ → 浏览器”在原上下文中新建后台空白 Page；不会访问旧地址、取消 Agent 或切换 Agent 的执行页。查看 Sheet 的 state、frame 和元素选取带明确目标，`viewed_tab` 表示正在查看的页面，`active_tab` 保留 Agent 执行目标的含义。画面、版本和输入必须与这张 Sheet 的绑定匹配。

同一窗口内的 Sheet 共享会话级人工租约，租约只保存在内存。关闭真实页面需要已接管的租约；Agent 控制时先提示接管，不静默中断任务。真实人工输入经过上下文、页签、generation 和租约校验后才作用到指定页面。关闭最后一页可以留下零页，不能为了维持旧的单视图假设偷偷创建替代页。

备份位于浏览器 localStorage：各 Dock 键附加 `:native-only:v1:backup`，新书签键为 `pogo:browser-bookmarks:v1`。回滚前先保留新数据；不能删除备份或用旧数据覆盖用户迁移后的修改。旧 iframe 登录状态不自动复制到原生上下文，必要时用户重新登录。

## 取消与持久化

取消会停止模型和工具工作，不丢弃构成会话记录的 message、tool-results 和 steer 事件。事件消费者仍须遵守既有“读到结束”的接口约定。取消回归以真实开始/取消/结束流程，从磁盘重开 Store，检查调用与结果完整配对、自身与委派用量准确，关闭后再打开不重复写入。该验收不追认早期已删除会话的数据恢复。

## 发布与回滚

1. 构建并发布相互匹配的 Go/UI 和 worker；明确设置 worker URL 与服务凭据。不要只更新其中一项。
2. 更新前确认无活动任务，保留旧镜像、配置和持久数据备份；保留浏览器本地存储备份。更新会清空内存中的浏览器页面和登录上下文。
3. 验证无前端订阅仍可执行、服务缺失无回退、退役入口零网站请求、迁移可修复、会话隔离、人工接管、取消后重新打开会话的数据完整性。
4. 当前版本只运行原生执行器。需要回滚时恢复上一配套版本及适用备份，不在新版中重新开启旧执行分支。无用候选环境在相应交付验证后停止，历史报告保持只读。

历史 auth/auth-auto 报告和判据可离线查阅，但不能用当前接口适配旧协议后重算旧成绩。当前浏览器评测须生成新产物并记录新的源码、Skill/schema 和环境标识；参考控制通过不等于真实模型或真实业务站点验收。

## 发布维护门禁

服务器读取 `<SessionDir 的父目录>/release-maintenance.json`。运维方以 0600 权限原子写入 `{"token":"64位随机小写十六进制"}` 后，普通 HTTP 请求（包括面板代理和 MCP）返回 503，内部定时任务暂停。格式错误或不可读的标记保持关闭。验收请求携带 `X-Pogo-Release`，仍必须通过原有账号、归属与 Origin 检查；该头在进入业务处理器或代理前删除，不是账号认证替代品。验收完成后由运维显式移除标记，服务不自行超时开放。

首次从不认识维护标记的旧镜像升级时，先检查所有账号、后台任务、工作流和定时任务，再停止旧主服务建立维护边界；新镜像首次启动即受标记保护。本机发布 hook 仅在计划任务为空时继续，不自动删除或禁用用户任务。若回滚到不支持标记的历史镜像，需单独确认恢复的访问状态，不能声称历史版本也提供此门禁。

镜像发布使用持久 `w_deploy/compose.release.yml`，原 `.env` 与 `compose.yml` 保持原字节。后续正常启动也读取固定镜像 ID。发布执行器仅在明确开关下接受旧 worker 未设置、目标为默认 `POGO_BROWSER_SETTLE_MS=2000` 的等价变更；必须同时证明规范化配置 hash 与实际运行镜像一致，不能绕过其他配置漂移。
