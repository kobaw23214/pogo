# 信息库

Manager 的“信息库”用于整理同一工作空间中所有 Agent 及其派生子 Agent 共用的资料。它独立于每个 Agent 的私人快捷方式和浏览器收藏。

## 使用

- 按文件夹组织文件和快捷方式，支持目录树展开、收起。
- 可浏览当前目录，或平铺全部条目；名称搜索展示匹配项及所在路径。
- 可以上传文件、创建快捷方式，或从已有 Agent 的私人快捷方式复制一份。
- 快捷方式复用现有编辑器，保留文字、附件、网页元素、技能、嵌套快捷方式及 Office 选区快照的顺序。
- 对话输入框中的信息库按钮将所选版本插入草稿，支持顶部附件和引用排列，不会自动发送消息。
- 点击 `.xlsx` / `.docx` 文件，直接在大尺寸弹窗中使用 ONLYOFFICE 只读预览，无需先引用到对话。预览固定到所选保存版本，关闭时释放临时会话，不修改信息库原件；打开失败可重试。与 Office 选区共用最大 256 MiB 的流式文档链路，其他格式仍使用原有文本、图片或 PDF 预览。

## Agent 读取

主 Agent 和获得授权的子 Agent 使用只读 `information` 工具：`list` 查看目录、`search` 搜索、`read` 读取指定条目。目录只提供元数据；正文按需读取，不会把整个信息库加入系统提示词。

读取文件时，后端校验原始字节并将选中文件复制到当前工作区的 `uploads/information/`，现有文件、Office 和批量处理工具可以继续使用。对副本的修改不会悄悄覆盖信息库原件。二进制文件不会被假装解析成正文。

资料里的技能名称、命令或网页内容属于数据，不能自行扩大工具权限。Office 选区保留其来源会话、版本和选择文本，不授予读取其他会话原文件的权限。

## 保存与引用

目录元数据采用版本校验，冲突时保留用户草稿并提示重试。条目保存不可变版本，文件采用内容摘要保存。改名、移动、编辑或删除当前条目后，已记录版本仍可供历史引用读取。

回答来源中的信息库引用记录条目、版本和快照摘要，点击可查看当时的版本。附件预览还会校验该附件属于这一版本，不能用任意磁盘路径或其他条目的句柄读取文件。

信息库按完整账户身份和受信任工作空间隔离，同一工作空间不再按 Agent 切分。上传的单文件上限为 512 MiB，正文读取和界面预览有独立的分页与大小控制。

第一版提供目录与文本检索，没有引入向量数据库、后台自动抓取或自动更新外部网站。
