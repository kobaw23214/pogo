# 浏览器可见证据与数值核验

这是通用浏览器的可选结构提取与计算辅助层。页面 CDP、真实网络与 Console 观察见[浏览器调试协议](browser-devtools.md)；本模块支持的 HTML 结构和单位范围不代表通用浏览器的全部能力。

原生 `snapshot` 和 `extract` 继续返回正文与元素引用，并附加可见 DOM 的 `evidence`。表格保留原始行、空单元格、表头和跨度；定义列表保留字段对；标题、段落和明确的 `aria-current=page` 标记保留来源。结构复杂或截断时不猜对应关系。当前只保留原生执行器；历史回执保持只读。

每次一致读取带独立观察 ID、URL、frame、tab、文档及 DOM 版本、采集时间和内容 SHA。读取前后文档变化或版本覆盖不完整时不发布有效结构证据；只需重新读取，不重放提交。结构路径与数量引用都是只读材料，不能替代点击用的 `eN`。

worker 从完整的表格字段、定义字段或单一段落生成随机 `quantity_ref`，保存不可变来源。支持明确单位的精确标量，不把裸记录编号、日期、范围、约数、百分比、含糊货币符号、科学记数或截断文字当作精确量值。最多保留32个观察、每观察100个量值；取消、接管、重建或缓存淘汰后须重新读取。

`calculate` 仅在原生工具声明中可用，输入为 `operation` 和最多16个不同的真实 `quantity_refs`。它不接收数字、单位、表达式或调用方提供的来源。

| 操作 | 结果 |
| --- | --- |
| compare | 两值的 less / greater / equal |
| difference | 第一个减第二个，保留符号 |
| sort | 升序及并列组 |
| sum | 所列观察量值的精确和 |

精确十进制计算支持 g/kg、秒/分钟/小时的确定换算；天、月、年各自仅同单位计算。CNY/RMB/人民币归 CNY，“元”保持自己的单位；跨币种及不确定格式返回 unsupported。`0.1 + 0.2` 可得到精确 `0.3`，但不能把2年默认为730天。

结果明确为 `as_observed`、`current_state_verified:false`、`verifies_entire_answer:false`。跨页面旧观察可用于比较，不保证当前价格未变、记录语义正确或已覆盖全站。最便宜的结论还需候选范围完整，多个最低值必须报告并列；商品序号和加载次数不能当页码。采集器在网页脚本运行前捕获所需的浏览器原生 DOM 接口，避免调用网页替换过的读取方法；页面提供的数据仍不可信，采集与计算不能验证网站陈述本身真假。

独立 `browser-runtime/eval/evidence/` 四任务套件验证真实来源与计算接口。模型只收到 URL 和业务目标，最终回答仍是自然语言；接口成功不自动通过完整答案。参考/无动作控制仅验证判据，模型回答须保留原始轨迹再逐项复核，不覆盖旧通用及认证成绩。入口和验收边界见该目录 README。
