These are the retired tabCapture launcher, extension codec, density and sender-policy tests. They are preserved verbatim for historical reference and are outside the active `test/*.test.js` suite. Their original relative imports intentionally remain unchanged; these snapshots are not executable against the retired production source. Their old results do not provide Wayland coverage. Active Wayland tests use the default worker, real compositor/Chromium, original DOM and a separate WebRTC receiver.
